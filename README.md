# Digital Grievance Intelligence

Digital Grievance Intelligence is a web-based complaint management system developed using Python Flask and MySQL.

The system allows users to register, log in, submit complaints, and track the status of their complaints. Administrators can log in to an admin dashboard, view complaints, and update their status.

## Features

- User Registration
- User Login
- Secure Password Hashing
- Submit Grievances
- View Submitted Complaints
- Track Complaint Status
- Admin Login
- Admin Dashboard
- View All Complaints
- Update Complaint Status
- MySQL Database Integration
- Flask Web Application

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL
- Git
- GitHub
